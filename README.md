# PortFolio
It is a simple Weather App i made to learn Tailwind and JavaScript.
## Description
So This a weather app, You enter the city name in the input and click fetch button and you get the data of the weather. Like temperature , humidity, sky data and a fun emoji. It got Day And night mode system level.

## Getting Started
### Dependencies
* A modern Browser
* VS Code optional
* Python Optional
### Installing
* Download the Github Repo As Zip
* Or do ```git clone https://github.com/rehan-kasim/Weather-App```
### Executing Program
* Download the repository add your openweather api in the .env it and double click the index.html to open in browser. Or just Open this url ```https://weather-app-src.vercel.app```
* Or launch a python Local Server Use ``` python -m http.server``` and Open port 8000.
* Or Use live Server Extension In VS Code.
### Rebuild Tailwind
* Do ```npm install tailwindcss @tailwindcss/cli```
* Then ```npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css```
* And you Are good to go
