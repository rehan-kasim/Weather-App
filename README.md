# Weather App
It is a simple Weather App i made to learn Tailwind and JavaScript.
## Description
So This a weather app, You enter the city name in the input and click fetch button and you get the data of the weather. Like temperature , humidity, sky data and a fun emoji. It got Day And night mode system level.
## Built With
* HTML, JavaScript
* [Tailwind CSS v4](https://tailwindcss.com/)
* [Vite](https://vite.dev/)
* [OpenWeather API](https://openweathermap.org/api)

## Getting Started
### Requirements
* [Node.js](https://nodejs.org/) (LTS version)
* A free [OpenWeather API key](https://openweathermap.org/api)
* modern browser
### Using
* open this link ```weather-app-src.vercel.app```
* or follow the below instruction to run locally
### Installing
* ```git clone https://github.com/rehan-kasim/Weather-App```
* ```cd Weather-App```
* ```npm install```
### Setting up your API key
* Create a file named `.env` in the project root:
* ```VITE_API=your_openweather_key_here```
### Running locally
* ```npm run dev```
* Then open the URL it prints (usually http://localhost:5173).
### Building for production
* ```npm run build```
* ```npm run preview```
* The build output goes into the `dist` folder.
